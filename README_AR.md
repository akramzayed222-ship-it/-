# المفيد في الرياضيات — تطبيق Android (v4.1.2)

## ما يتضمنه المشروع
- نسخة HTML المصححة مع ضبط أحجام الرموز الرياضية للشاشات الصغيرة.
- تطبيق Android مبني على WebView مع `setTextZoom(100)` وتعطيل التكبير المزدوج.
- سير عمل GitHub Actions لبناء APK debug والتحقق من توقيعه وحساب SHA-256.

## البناء الآلي
1. افتح تبويب **Actions** في المستودع.
2. اختر **AL-MOFEED Android APK Build** وشغّل `Run workflow` أو ادفع تغييرًا إلى فرع الإصلاح.
3. بعد نجاح جميع الخطوات، نزّل artifact باسم `ALMOFEED-Mobile-Font-Fix-APK`.
4. يحتوي الأثر على `app-debug.apk` وملف SHA-256.

## بوابات الجودة
- يجب أن يكون ملف HTML الجذري مطابقًا بايتًا ببايت لنسخة `app/src/main/assets/index.html`.
- لا يُعلن نجاح البناء قبل نجاح Gradle والتحقق من توقيع APK.
- لا يُعلن الاختبار على الهاتف قبل تثبيت APK وتشغيل الحالات الرياضية على جهاز فعلي.

## أيقونة التطبيق
- أيقونة Android تكيفية مشتقة من علامة الجذر الرياضية الأصلية في شعار PWA للمفيد، بألوان الهوية البحرية والسماوية.
- يتضمن المشروع أيقونة متجهية بديلة للأجهزة الأقدم من Android 8.
